Язык программирования РефалАБ (RefalAB)
------------------------------------------

Современный диалект языка [Рефал-2](http://www.refal.net/~belous/refal2-r.htm)
с компилятором и интерпретатором на C.

### Особенности

- Полная совместимость с Рефал-2 — существующие программы работают без изменений;
- Большие числа — арифметика произвольной точности до 4294967295;
- Диапазоны в спецификаторах — ['a'..'z'], [10..100], [..0xff], [1000..];
- Богатая стандартная библиотека — арифметика, битовые операции, работа с файлами, множества, функции высшего порядка;
- Встроенный отладчик — трассировка, точки останова, пошаговое выполнение;
- Высокая производительность — быстрее Рефал-5 и Рефал-5 Лямбда;
- Кроссплатформенность — Windows (Mingw-w64 LLVM) и POSIX (Linux, macOS).

### Системные требования

- Компилятор C Clang,
- Make или совместимая система сборки,
- POSIX-совместимая среда или Windows с Mingw-w64 LLVM.

### Сборка

Инструкции по сборке находятся в файлах:
- [Make.Windows.md](Make.Windows.md) — для Windows,
- [Make.POSIX.md](Make.POSIX.md) — для POSIX (Linux/macOS).

### Документация

Полная документация языка РефалАБ находится в папке [docs](/docs).

### Отличия от Рефал-2

#### Новые возможности

##### Диапазоны в спецификаторах:

    $SPEC Letter ['a'..'z'] ['A'..'Z'];
    $SPEC Digit ['0'..'9'];
    $SPEC Range [10..100];

##### Функции высшего порядка:

    $FUNC Double
    {
        (e.N) = (<Add (e.N) e.N>);
    }
    
    $FUNC Main
    {
        = <Map Double (1) (2) (3)>;  // (2) (4) (6)
    }

#### Расширенная библиотека

- Арифметика больших чисел: Add, Sub, Mul, Dr, Div, Mod, Gcd;
- Битовые операции: Band, Bor, Bxor, Bnot, Shl, Shr, Bitand, Bitor, Bitxor, Bitnot, Bitsh, Bitrot;
- Работа с файлами: Load_File, Save_File, FRead, FWrite, FOpen, FClose;
- Работа со строками: Numb, Symb, Upper, Lower, Trim;
- Сортировка: QSortN, QSortW, MinN, MaxN, MinW, MaxW;
- Множества: SetW, SetN, SetW_Union, SetW_Intersect, SetW_Diff;
- Функции высшего порядка: Apply, Map, FoldL, FoldR;
- Системные функции: System, Get_env, Change_dir, Arg, Time.
