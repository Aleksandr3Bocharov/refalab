## Особенности

- **Знакомый синтаксис.** Основан на синтаксисе Рефал-5 с семантикой Рефал-2.
- **Длинные числа.** Арифметика над целыми числами произвольной длины;
  макроцифра принимает значения от 0 до 4294967295.
- **Диапазоны в спецификаторах:** `['a'..'z']`, `[10..100]`, `[..0xff]`, `[1000..]`.
- **Богатая стандартная библиотека:** арифметика, битовые операции, работа с файлами
  и каталогами, множества, сортировка, лексический анализ, время, функции высшего порядка.
- **Встроенный отладчик:** трассировка, точки останова, пошаговое выполнение.
- **Высокая производительность.** В сравнительных замерах на одинаковых программах
  (без уникальных функций РефалАБ) РефалАБ заметно быстрее Рефала-5λ (в нативном режиме
  и в режиме C++), оригинального Рефала-2 и Рефала-5 из стандартной сборки
  и сопоставим с Рефалом-5, собранным с `-O2`.
- **Кроссплатформенность:** Windows (LLVM Mingw-w64) и POSIX (Linux, macOS),
  32- и 64-битные сборки.

## Быстрый старт

Нужны `clang` версии 18.1.8 или новее и `make` (в Windows — LLVM Mingw-w64 и `mingw32-make`).

```sh
# 1. Скачайте исходники и перейдите в папку refalab
git clone https://github.com/Aleksandr3Bocharov/refalab.git
cd refalab

# 2. Соберите компилятор и интерпретатор
make

# 3. Скомпилируйте и запустите пример
./refalabclg tests/hello
```

Результат:

```
Hello World!
```

В Windows запуск примера выглядит так: `refalabclg tests\hello`.

Исходный текст примера (`tests/hello.ref`):

```refal
$START HELLO;

$ENTRY Go;
$EXTERN Print;

$FUNC Go
{
    = <Print 'Hello World!'>;
}

$END.
```

## Сборка

Подробные инструкции по сборке и проверке:

| Платформа | Инструкция | Требуется |
|---|---|---|
| Windows | [Make.Windows.md](Make.Windows.md) | [LLVM Mingw-w64](https://github.com/mstorsjo/llvm-mingw) 18.1.8+ (POSIX threads, UCRT), `mingw32-make` |
| Linux / macOS | [Make.POSIX.md](Make.POSIX.md) | `clang` 18.1.8+, `make` |

Список всех целей сборки выводит команда `make help` (в Windows — `mingw32-make help`).

Результат сборки:

- компиляторы `bin/refalabc` и `bin/refalabc_dbg` (режим отладки);
- библиотеки интерпретатора `lib/librefalab.a` и `lib/librefalab_dbg.a`;
- объектные файлы запуска программ и отладчика в `lib/obj/`.

## Запуск программ

В корне репозитория лежат скрипты, которые компилируют, компонуют и запускают
РефалАБ-программу (имя файла указывается без расширения `.ref`):

| Скрипт (POSIX / Windows) | Назначение |
|---|---|
| `refalabco` / `refalabco.bat` | компиляция в объектный файл |
| `refalabclg` / `refalabclg.bat` | компиляция, компоновка и запуск |
| `refalabclg_dbg` / `refalabclg_dbg.bat` | то же в режиме отладки |
| `refalabdclg` / `refalabdclg.bat` | запуск под отладчиком |
| `refalabdclg_dbg` / `refalabdclg_dbg.bat` | запуск под отладчиком в режиме отладки |

Для проверки сборки запустите тесты `hello`, `fact`, `test0`…`test5` из папки [tests](tests).
Завершающие сообщения `Recognition impossible` в `test1`, `test4` и `test5` — штатные:
в этих тестах проверяется неотождествление.

## Примеры возможностей

### Диапазоны в спецификаторах

```refal
$SPEC Letter ['a'..'z'] ['A'..'Z'];
$SPEC Digit ['0'..'9'];
$SPEC Range [10..100];
```

### Функции высшего порядка

```refal
$START HIGHER;

$ENTRY Go;
$EXTERN Print, Map, Add;

$FUNC Go
{
    = <Print <Map (Add (2)) 0 1 2>>;   // прибавить 2 к каждому терму: 2 3 4
}

$END.
```
